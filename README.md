# NGO Website

This project is a website for an NGO. It is being built to support a non-governmental organization with an online presence, information about its mission, programs, events, and ways for supporters to connect.

## Project Purpose

- Showcase the NGO's mission and values
- Provide information on programs and services
- Highlight upcoming events and volunteer opportunities
- Offer contact details and donation/support options

## About

The website is designed for an NGO to communicate its impact, share stories, and make it easy for the community to engage with its work.
