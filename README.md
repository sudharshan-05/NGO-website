# NGO Connect

A modern NGO website designed to connect volunteers, donors, and communities.

## Features

* Interactive Chennai Impact Map
* Volunteer Registration
* Donation Support
* Event Gallery
* Project Showcase
* Contact Section

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Vite

## Getting Started

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
